# 🏍️ Motorcycle Tax Calculator

## 🇬🇧 English

A Python program for calculating the estimated **registration tax for motorcycles**.

The calculation is based on:

* Retail price
* Engine capacity (cc)
* Registration date
* DEFK date
* Vehicle age
* Age discount

### Output

* Taxable amount
* Engine capacity tax rate
* Age discount rate
* Vehicle age in months
* Registration tax

### Files

* `main.py` — User input and results
* `motorcycle.py` — Tax calculation logic

## 🇬🇷 Ελληνικά

Ένα πρόγραμμα σε **Python** για τον υπολογισμό του εκτιμώμενου **τέλους ταξινόμησης μοτοσυκλέτας**.

Ο υπολογισμός βασίζεται σε:

* Τιμή λιανικής
* Κυβισμό (cc)
* Ημερομηνία κυκλοφορίας
* Ημερομηνία ΔΕΦΚ
* Παλαιότητα οχήματος
* Έκπτωση παλαιότητας

### Αποτελέσματα

* Φορολογητέο ποσό
* Φορολογικός συντελεστής κυβισμού
* Ποσοστό έκπτωσης παλαιότητας
* Μήνες παλαιότητας
* Τέλος ταξινόμησης

### Αρχεία

* `main.py` — Είσοδος χρήστη και εμφάνιση αποτελεσμάτων
* `motorcycle.py` — Λογική υπολογισμού
