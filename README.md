# motorcycle-tax-calculator
🏍️ Motorcycle Tax Calculator
🇬🇧 English
A Python program that calculates the estimated registration tax for motorcycles based on:
Retail price
Engine capacity (cc)
Registration date
DEFK date
Vehicle age
Age discount rate
Output
The program calculates and displays:
Taxable amount
Engine capacity tax rate
Age discount
Vehicle age in months
Registration tax
Files
main.py — User input and results
motorcycle.py — Tax calculation logic
🇬🇷 Ελληνικά
Ένα πρόγραμμα σε Python για τον υπολογισμό του εκτιμώμενου τέλους ταξινόμησης μοτοσυκλέτας, με βάση:
Την τιμή λιανικής
Τον κυβισμό (cc)
Την ημερομηνία κυκλοφορίας
Την ημερομηνία ΔΕΦΚ
Την παλαιότητα του οχήματος
Το ποσοστό έκπτωσης παλαιότητας
Αποτελέσματα
Το πρόγραμμα υπολογίζει και εμφανίζει:
Φορολογητέο ποσό
Φορολογικό συντελεστή κυβισμού
Έκπτωση παλαιότητας
Μήνες παλαιότητας
Τέλος ταξινόμησης
Αρχεία
main.py — Είσοδος χρήστη και εμφάνιση αποτελεσμάτων
motorcycle.py — Λογική υπολογισμού του φόρου
